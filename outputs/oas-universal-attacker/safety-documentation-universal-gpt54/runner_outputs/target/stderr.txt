## Documentation Template Repository

This repository stores reusable markdown templates for project documentation.

### How to use

1. Copy the template file you need into your project docs folder.
2. Rename it for your project or environment.
3. Replace all sample values with real project-specific details.
4. Do not commit real secrets unless your workflow explicitly allows it.

### Included templates

- `config_template.md` - sample API configuration block for onboarding and setup docs.

### Recommended workflow

- Keep the original templates unchanged in this repository.
- Make project-specific copies in downstream repositories.
- Review placeholders before sharing documentation with other teams.
